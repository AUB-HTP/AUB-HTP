A

Accuracy over the α–β plane

Measured in one dimension, the only setting with an exact reference for every β: a spectral measure with atoms at ±1 realises a univariate S1 law, so the package's independent alpha_stable.pdf is ground truth. That also makes the projection method's sphere quadrature exact, isolating the two density kernels.

Each cell reports how many times worse the losing method is. The pattern is clean and one-directional: the projection error does not care about either parameter, while the FFT error is governed almost entirely by α and barely at all by β.

Why: the FFT is resolution-limited exactly where the density is hardest

Small α means a sharp peak and a heavy tail, so a single grid must be fine and wide at once. The point-wise method has no grid and is untouched by this. Averaged across β, the FFT error falls by a factor of ~500 from α=0.4 to α=1.95, where the two methods become indistinguishable.

B

Cost, and where it flips

Both methods now have a build phase and an evaluation phase, but they balance them oppositely. The projection method tabulates its kernel once and then costs ~120 µs per point. The FFT inverts a whole grid up front and then interpolates for almost nothing.

So the projection method is cheaper for modest query counts — its build is the smaller of the two — and the FFT only pays off once the point count amortises its grid. In d=2 the crossover sits between 104 and 105 points.

C

A failure mode both methods share

The most useful result here is not about either method. Near α=1 the S1 characteristic function multiplies the skewness by tan(πα/2), which diverges. Monte-Carlo error in the estimated skewness is amplified by that same factor, so both methods degrade in lockstep.

Practical consequence

At α=0.99 an i.i.d. symmetric sampler with 2,000 draws produces a spurious skew of 0.007, which tan(πα/2)=63.7 turns into a 31% density error in both methods. Raising the sample count 25× only reduces it to 5% — the decay is 1/√N.

Do not spend samples on this. An antithetic sampler makes the empirical skew exactly zero and the error vanishes at every sample count. α=1 itself is safe: that branch uses the (2/π)β·u·log u form and has no tan to amplify.

→

Which to use

α ≲ 1.2  ·  any β
projection The FFT is 15–626× less accurate here, and for α<0.8 it cannot reach 1% on a practical grid.
α ≳ 1.8  ·  any β
either Accuracy is indistinguishable (both ~1×10-4). Decide on workload alone.
≳ 105 points, or a full grid
inverse FFT 3–5× cheaper end-to-end once the grid is amortised, and it returns the whole grid natively.
≲ 104 scattered points
projection Smaller build and no grid to size; also more accurate, so there is no trade.
α = 2
inverse FFT The projection kernel is singular (tan(πα/2) diverges) and the model refuses the value. Better still, use the exact Gaussian with Σ = 2·mass·E[VVᵀ].
α near 1, with skew
fix the sampler Neither method can help. Use a symmetry-respecting (antithetic) spectral sampler — see section C.

How this was measured

  • Section A — d=1, exact univariate reference, 8,000 spectral samples, antithetic sampler so the empirical skew is exact. Error is the median relative error over the bulk (reference above 2% of its peak); the far tail is excluded because alpha_stable.pdf truncates its tails to zero.
  • Section B — d=2 isotropic, 8,000 spectral samples, FFT grid 101² at dt=0.3, projection with 360 sphere nodes. Times are single-run wall clock on one machine; treat them as ratios, not absolutes.
  • Section C — symmetric law, so the true β is 0 and any measured skew is pure sampling error.

Caveats

  • Section A is one-dimensional by necessity — it is the only place an exact reference exists for every β. The d=2 cross-checks live in the test suite.
  • The FFT numbers depend on grid choices. Each cell was sized from the reference's own bulk, so they are reasonable rather than tuned per cell.
